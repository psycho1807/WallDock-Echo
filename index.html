Si la vue reste vide, Home Assistant interdit peut-être son affichage intégré. Utilise « Ouvrir dans Silk ».

Connexion Home Assistant

Indique l'adresse HTTPS de ton Home Assistant (par exemple ton adresse Nabu Casa). WallDock Echo ouvre Home Assistant dans Silk : aucune clé ni mot de passe n'est enregistré ici. Les pages d'entités nécessitent un compte Home Assistant autorisé.

Configuration recommandée : crée dans Home Assistant un tableau de bord WallDock Echo, puis renseigne les chemins de ses vues (exemple : /wall-dock-echo/lumieres). Tu peux ajouter les équipements avec l’éditeur visuel de Home Assistant. Vide = chemin par défaut.

Désactivé par défaut : Silk et Home Assistant peuvent bloquer les vues intégrées. Le mode direct ouvre la vue dans Silk. Utilise le bouton retour du navigateur pour revenir à WallDock.
